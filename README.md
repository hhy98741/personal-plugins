# Claude Plugins

A personal collection of Claude Code plugins.

## Plugins

| Plugin | Description |
|---|---|
| [app-builder](plugins/app-builder/) | Breaks down product requirements into epics and features, then builds them using a team of specialized subagents |
| [dev-hooks](plugins/dev-hooks/) | Hooks for logging, safety checks, TTS voice notifications, and session management |
| [dev-skills](plugins/dev-skills/) | A set of common skills to use across multiple projects |
| [voice-notifications](plugins/voice-notifications/) | Plays spoken-audio clips on session start/end, waiting for input, and agent/subagent completion |

See each plugin's README for specific setup instructions.
